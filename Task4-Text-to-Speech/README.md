# Task 4 – Text to Speech

## Description

This project converts user-entered text into speech and saves the generated audio as a WAV file.

The project uses Python and the `pyttsx3` library for local text-to-speech conversion.

## Requirements

* Python 3
* pyttsx3

## Installation

Install the required library using:

```bash
pip install pyttsx3
```

## How to Run

Run the following command:

```bash
python app.py
```

Enter the text when prompted:

```text
Enter your text: Hello, this is a test.
```

The program generates an audio file named:

```text
output.wav
```

## Project Structure

```text
Task4-Text-to-Speech/
│
├── app.py
├── output.wav
├── README.md
└── requirements.txt
```

## Features

* Takes text as input from the user
* Converts text into speech
* Works locally without OpenAI API credits
* Saves the audio as a WAV file
