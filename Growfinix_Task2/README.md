\# AI-Powered Data Extraction



\## Project Overview

This project extracts important information from unstructured text

and converts it into structured JSON format using Python.



\## Objective

To automatically extract customer names, requested dates,

and destinations from text messages.



\## Technologies Used

\- Python

\- Regular Expressions (re module)

\- JSON



\## Features

\- Extracts customer names

\- Extracts requested dates

\- Extracts destinations

\- Displays extracted information in JSON format



\## Example Input

Hi, my name is chitu. I need a hotel booking in Delhi on 25 November.



\## Example Output

{

&#x20;   "customer\_name": "chitu",

&#x20;   "requested\_date": "25 November",

&#x20;   "destination": "Delhi"

}



\## How to Run

1\. Install Python.

2\. Open Command Prompt in the project folder.

3\. Run: python main.py

4\. To test the project, run: python test.py
