# Task 5 AI Chat

## Run locally

1. Copy `.env.example` to `.env` and replace the placeholder with your OpenAI API key.
2. From this project folder, run `npm install` and then `npm run dev`.
3. Open the Vite URL shown in the terminal. The command starts both the frontend and the AI server.

The chat uses OpenAI's `gpt-4o-mini` model. Keep your API key private; `.env` is excluded from Git.
